# .claude/rules/ — правила под конкретные файлы

Пока пусто. Заполняется после выбора стека.

Правило с полем `paths` во frontmatter попадает в контекст только тогда,
когда Claude читает подходящий файл. Это способ дать частные требования,
не занимая контекст в каждой сессии.

Пример, когда стек определится:

```markdown
---
paths:
  - "templates/**/*.html"
---

# Шаблоны

- логика в шаблонах минимальная: только вывод и простые условия
- вычисления делаются во view и передаются готовыми
- каждый блок больше 20 строк выносится в отдельный файл через include
```

Кандидаты на отдельные правила: работа с формами, запросы к базе,
обработка загрузки файлов, стили. Заводить по мере появления
повторяющихся замечаний — если приходится править агента второй раз
за одно и то же, это правило.
